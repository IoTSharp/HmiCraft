# 工业 HMI 首版硬件选型草案

研究日期：2026-10-10，Asia/Shanghai。用户要求按成本和性能制定硬件；本轮查阅芯片厂和板卡厂资料，尚未采购、接线或跑性能测试。下面区分已查规格、设计建议、预算和验收，不能宣称已经找到所有市场方案中的全局最优。

## 已确认的需求

- 工业 HMI，约 4.3～7 寸、触摸、24V 供电、RS485。
- LVGL/控件库/驱动编入稳定基础固件；日常更新生成布局的 BASIC、用户 BASIC、图片/字体/动画资源。
- 持续事件循环；监视 GPIO、温度、位置/计数、开关及模拟量状态，支持 ADC/PWM、串口和 TCP 类协议。
- 高速计数由硬件承担，不由 BASIC 做轴运动闭环。
- OPC UA 经网关转换为 Modbus/TCP，首版 MCU 不承担 OPC UA 栈。
- MCU 未限定必须 STM32；具体接口数量、传感器型号、分辨率、温度等级、IP 防护、采购数量与成本上限尚未给定。

## 建议结论

**主选 ESP32-P4 + 外部内存 + 4.3～7 寸电容屏 + 有线以太网 + 独立工业 IO/电源板的架构；STM32H743/H7 同级配外部 SDRAM/Flash 作为备选。** P4 的开发板内存、显示和网络选择更适合资源包/BASIC/动画的组合，当前样品标价有吸引力。是否最终采用，要先验证 IoTEmbedded 的 ESP-IDF port、所选屏幕时序、引脚分配和性能；不能把换 MCU 的软件成本算成零。

建议先选 **一个** 具备有线网口的 P4 参考板做主线：`ESP32-P4-ETH` 是可检查的候选。屏幕选 4.3～7 寸中有厂商明确驱动/接线支持的一款，完成 DSI/RGB、连接器、供电、触控与旋转核对后冻结准确 SKU；它的商品页套装含 10.1 寸选项，不能直接把 KIT-B 当成所需 7 寸屏。没有必要同时采购三种主控。

已集成 7 寸的 `ESP32-P4-WIFI6-Touch-LCD-7B` 也是候选，页面列出 RS485/CAN/UART 等，但没有确认板载 RJ45；若选择它，应先证明有线以太网扩展的接口、引脚和带宽。不能因 P4 芯片有 MAC 就声称整板已经有网口。

`ESP32-S3-Touch-LCD-4.3B` 可作为低成本 UI/脚本样机：24V 范围和部分工业 IO 更接近目标；但 8 MB PSRAM 余量、有线网口扩展和 GPIO 复用必须核查，因此暂不把它选为完整工业主板。最终评价包含板卡、扩展、固件移植和验证成本，而不只看 MCU 单价。

## 建议参考设备配置

这是可讨论和验证的参考配置，不是已下单 BOM 或用户确认的通道数。

| 部分 | 建议基线 | 原因/需确认 |
|---|---|---|
| 主控/内存 | P4；32 MB PSRAM；32 MB NOR 或同等可用资源 | 同时容纳 LVGL、BASIC AST/堆、字体/图像缓存和双代际包；实际分区预算后定 |
| 屏幕 | 先一款 4.3～7 寸电容屏；800×480 或 1024×600 作为资源测量档 | 精确 SKU/接口/时序须验证；分辨率不是通过缩放桌面示例自动获得 |
| 网络 | 100 Mbps 有线 Ethernet 为建议必备，WiFi 作为可选扩展 | OPC UA 网关经 Modbus/TCP 接入，工业现场调试与包更新更直接 |
| 总线 | 1 路隔离 RS485；1 路独立串口调试/扩展 | 不假设原板 RS485 已隔离；隔离电源、ESD、终端/偏置和方向控制需明确 |
| 数字 IO | 参考 8 DI + 4 DO，优先独立工业 IO 板或 Modbus 远程模块 | 电平输入、干接点、输出驱动与负载区别很大；不将 24V 直接接 MCU GPIO |
| ADC/温度 | 参考 2～4 通道扩展位；温度优先已有 RS485 变送器或专用采集模块 | PT100、热电偶、NTC、0～10V、4～20mA 需要不同前端，按实际传感器选择；不预装所有接口 |
| PWM/计数 | 参考 2 PWM、1 组硬件计数/编码器接口扩展位 | 频率、输出电气形式、计数范围和 pin mux 在首板冻结；不是运动控制器 |
| 操作输入 | 触摸 + 若干具名实体按键；编码器可选 | 实体输入与屏幕控件共享受控动作模型 |
| 电源与结构 | 24V 输入，经保护和 DC/DC 到逻辑/屏电源；端子、外壳与散热单列 | 保护等级、工作温度、EMC/ESD 和连续运行是后续实物门禁 |
| 包存储 | 至少保留当前有效代际和候选代际，资源按需读取 | 32 MB NOR 不一定足够所有动画/字体；先测量，必要时扩大存储或减少资源规模 |

接口多样时，采用“显示主板 + 可选 IO/协议模块”比给每款屏集成所有传感器前端更易控制成本。通用模块驱动和能力归 IoTEmbedded，HMI 只绑定具名资源。推荐先做 GPIO/一个温度源/Modbus RTU/TCP 的闭环，再逐类增加设备驱动。

## 成本模型

整机成本 = 主控及内存 + 屏/触控 + 电源保护 + Ethernet PHY/磁性件 + 隔离 RS485 + IO 前端 + PCB/连接器 + 外壳/装配/测试。软件移植、模具/认证/测试工装是一次性工程费用，OPC UA 网关是独立设备/软件成本；现有工业 PC 可承载网关时不重复购买主机。

可先将**单台工程样机预算目标设为人民币 700～1,200 元，后续百台级基础机 BOM 目标 400～700 元**用于询价和裁剪讨论。它们是工程预算建议，不是依据汇率换算的厂商报价，也不是已承诺的量产价格；模拟量前端、隔离通道、外壳和采购数量确定后必须重新分项报价。高精度采集/全通道隔离等扩展单独计价，不能隐藏在低价屏板价格里。

先比较“同样屏幕、网口、隔离与 IO 配置”的总成本，再决定 P4 或 STM32H7。若新增 ESP-IDF port 的实际工作量超过项目可承受范围，STM32H7 的复用价值可能超过元件差价，保留切换门禁。

## 性能与容量验证计划

不是所有外部 PSRAM 都适合所有 DMA/实时缓冲。需要分别验证可 DMA 内存、缓存一致性、栈/内部堆和大资源缓存；用总内存数代替可用内存会误导选型。

RGB565 单帧：800×480 = 768,000 字节，1024×600 = 1,228,800 字节；双帧分别约 1.46 MiB、2.34 MiB。仅 800×480×2×30 就有约 23 MB/s 原始像素量，不能简单假设 SPI 小屏方案能满屏每秒 30 帧；RGB/DSI、局部刷新与缓存需按实测选择。

建议第一轮测量语料：10 页面、每页 50 个可见对象、200 个变量、1～2 个小区域动画、中文子集字体、1 路 RS485 设备和 1 路 Modbus/TCP 网关。把响应时间、刷新率、CPU/堆/栈峰值、脚本超时后的恢复记录为基线；此规模是测量提案，尚未通过。先定资源限制，再开放设计器可选控件/动画，不能承诺任意 GIF/视频和无限脚本。

验收顺序：板卡/屏/触摸最小程序 → LVGL 固定场景 → BASIC 创建同一场景 → GPIO/传感器/协议并发 → 包更新 → 异常和断电恢复 → 24V/隔离/EMC/长稳。每步独立记录，源码和官方演示不能替代本项目实测。
