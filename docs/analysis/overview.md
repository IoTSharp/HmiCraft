日期：2026-10-10。本仓通过商业产品、开源工具、运行时与用户场景形成独立需求。研究对象用匿名编号表达；来源名称、安装路径、型号、源文件摘要、原始页面和详细映射仅保留在忽略的私有研究资料中。实际采用的开源依赖保留准确名称及许可归属。

## 证据范围

商业样本 A 已完成安装层盘点、帮助与配置分析：6,370 文件、648 页面/目录索引、46 功能域、10 条旅程、72 个唯一设备配置与139条协议配置。它是目前详细静态研究的一个样本，不能写成已经实测全部市场产品。

主程序为原生x86 PE、无CLR。该事实说明应从用户行为、格式和接口合同建立独立实现，不能假设存在可直接还原的托管源代码。源文件身份与精确摘要在私有证据中校验，仓库不展示这些识别信息。

## 对本项目的结论

1. 编辑模型、UI、运行时和设备交付分离，不能把画布等同完整HMI平台。
2. 采用VB6式对象/属性/事件工作流；布局生成BASIC，生成代码与用户逻辑分离。
3. 主入口复用Web编辑器；.NET承担已有核心能力和按需本地集成；不维护两套重复画布。
4. IoTEmbedded负责通用框架/驱动/解释器；本仓负责HMI语义、LVGL封装、包、事件、变量、资源和部署。
5. 新设备闭环优先；外部旧格式/宏/设备兼容按匿名样本独立验收，不能成为新产品主线前置。
6. 竞品参数与限制只用于发现问题。本项目按实际硬件预算与用户场景确定能力，不照搬某款产品的全部数值。
