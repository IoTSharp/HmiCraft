日期：2026-10-10。以下归纳来自商业样本 A 的文档静态研究，不是该样本实际运行或本项目已实现的证明。原始来源、路径、摘要和页面映射在忽略的私有研究资料中；仓库用 A-Mxx 对应匿名来源。

## 覆盖范围

已索引648个页面/目录，形成46个功能域和10条操作旅程。中英文材料有继承、链接和数值矛盾；文档声明不能替代行为验证。源安装只读，未运行原程序、连接PLC或写入设备。没有把本次单一样本的详细分析包装成全市场实测。

## 主要操作旅程与验收场景

1. **新建并绘制工程**：选择设备型号、方向和工程路径 → 选择通信厂商/系列 → 选择启动画面 → 在画面添加位按钮和数值控件 → 将二者绑定 LB/LW 或外部地址 → 保存 → 重新打开。验收要覆盖型号分辨率、稳定对象编号、保存后的属性不丢失以及未保存提示。来源 M01、M03、M08、M13。
2. **批量编辑多画面**：复制画面和控件 → 多重复制并递增地址 → 调整层次/组合/对齐 → 地址/文本/控件一览表定位 → 撤销和重做。手册警告触摸对象组合可能失去触摸功能，这是需要实际确认的兼容行为，不能直接当成新产品应有缺陷。来源 M04–M05、M23。
3. **配置 PLC 与状态交互**：建立串口 → 添加协议实例与站号 → 设置超时/重试/读写长度 → 控件选择该设备地址 → 监视和写入 → 根据连接状态显示异常。不要把本地内存正常变化当作 PLC 已读写成功。来源 M37–M41、保留寄存器页。
4. **报警与追溯**：配置位或阈值规则 → 放置实时和历史报警控件 → 触发/恢复 → 确认 → 查询、导出或清除。报警的激活、恢复、确认、历史保留需要独立状态，具体时间戳和重复报警规则尚未从运行证据确认。来源 M18、M31。
5. **采集与趋势**：定义采集地址和数据类型 → 配置周期/边沿/整点 → 绑定趋势及历史显示 → 容量到达阈值 → 通知/停止或其他满后策略 → 导出。实时数据与历史持久化不能混为一种缓存。来源 M16–M17、M30。
6. **配方往返**：定义长度、数量、数据类型与 PLC 起始地址 → 输入或导入 CSV → 选择当前配方 → 写入 PLC → 读回 → 保存或另选配方 → 导出 CSV。需要分别验证当前编辑缓存、已保存表格、PLC 实际值三者。来源 M34。
7. **宏驱动行为**：建立 C 风格宏 → 声明地址变量 → 插入函数或图形库 → 编译诊断 → 绑定全局/初始化/画面/窗口/控件事件 → 在相应生命周期执行。原文限制说明宏不能仅依靠离线模拟完成兼容验收。来源 M32–M33、M42。
8. **编译与现场交付**：保存 → 编译 → 生成下载产物 → 选择 USB 或介质 → 原设备进入对应下载模式 → 下载 → 设备重新显示目标工程。新桌面应用能打开工程、生成文件或显示“成功”均不能替代原硬件行为验收。来源 M44。
9. **上载及重新编辑**：已有工程允许上载且操作者有对应凭据 → 选择硬件型号和保存路径 → USB 上载 → 打开上传的工程 → 编辑并重新编译。未验证原工程资源是否全部往返、不同固件是否兼容。来源 M45。
10. **多语言及权限**：设定语言表、用户等级和权限 → 为文本/报警准备多语言值 → 切换当前语言与用户等级 → 验证显隐、可触控、通知位和受保护操作。边界等级相等时的行为需实测，部分正文表述不严谨。来源 M22、M25、M28–M29。

## 需要独立验证的合同

- 编辑工程、可迁移资源包和设备运行产物是不同对象；不能按文件后缀猜压缩算法、版本或兼容关系。
- 状态按钮的按下、松开、点动、失焦和丢释放要分别验收；触摸许可与可见性不能混用。
- 地址类型、端序、动态偏移、数值转换、配方缓存与实际设备值要有固定向量。
- 文档里的宏语法、初始化数量、执行周期和内存限制存在产品特定约束；本项目使用BASIC合同，旧C宏兼容独立处理。
- 协议从站的功能码与寄存器映射存在文档冲突，应按授权报文、固定向量及真实设备确认。
- 文档中的设备型号、驱动名称或网络字样不能证明所有硬件、下载路径和在线模拟都支持。
- 多语言、用户权限、历史持久化、掉电恢复与错误质量分别设计，不能复用一份模糊状态。

## 我们据此实现什么

统一版本化工程模型，使用稳定对象ID，显式表达页面、对象、属性、事件、变量、逻辑IO、报警、采样和配方。Web编辑入口与BASIC/资源生成、同一runtime预览和真实设备交付共用合同。优先六基础控件与一个板卡的最小闭环，再扩展高级能力。
