## 已有测试的具体边界

核心测试在每次独占临时目录中运行，逐项 15 秒、总 90 秒，11 项上限；测试退出前清理自己创建的临时文件。保存错误回滚和取消有实际测试；断电、长路径、网络盘和多进程同文件竞争未验证。

桌面 smoke 调用真实桌面窗口的编辑与模拟操作，渲染并保存 PNG。拖拽中断测试覆盖收尾函数，尚未合成 OS 级鼠标捕获丢失；文件忙状态测试覆盖禁用和重入门禁，尚未在慢网络磁盘实测。文件选择框、输入法和辅助功能仍需人工旅程。

## 运行

```powershell
& 'C:\Program Files\PowerShell\7\pwsh.exe' -NoProfile -File .\eng\verify.ps1 -DesktopSmoke
```

最多五个顺序步骤，总时限 480 秒，每步独立上限。`Invoke-BoundedProcess.ps1` 记录 PID、创建时间、参数、父 PID、命令行、stdout/stderr 和退出结果；只回收经身份比对属于本任务的进程树。短进程可能在 CIM 采样前退出，必须保留取样空值，不能补造身份。失败日志保留，不能被后一次通过覆盖。

用户机器上的删除动作可能被工具策略拒绝；若清理受阻，保留并报告准确路径，不更换工具绕过策略。旧安装会话的临时日志因此仍保留。

## 设备工程后续门禁

当前只有方案和 IoTEmbedded 子模块，不安装未经需要的交叉编译器，也不把 `dotnet build` 当作设备构建。选定 STM32 时遵守 IoTEmbedded 的 VisualGDB/CubeMX 链路；选定 P4 时先完成独立 ESP-IDF port 和版本固定。每个固件产物关联本仓/子模块 SHA、LVGL 配置、工具链、板卡 profile 和 map/size；主机验证、板卡验证、工业验收分别记录。

主机 C runtime 验证需要先有 IEB-11 通用主机 port，使用与设备相同的 BASIC 内核。时钟/存储/模拟 IO 的注入归框架，LVGL 主机显示/输入适配归本仓；不得把另一套解释器的通过结果称为设备脚本一致性。

编译生成的 BASIC 语料必须进入 C#/C 共同验收，覆盖布局、属性默认值、重命名/删除引用、字符串转义/数值文化无关、用户代码保留、事件生命周期、预算拒绝和诊断定位。资源与字体使用自有或有明确来源的材料，不将原 外部样本 图库打入新设备包。
